# SolarisPredict-SL — Demo Pitch Video

90-second Remotion composition for the competition demo. Paired with the live walkthrough in [`../DEMO.md`](../DEMO.md).

## Quick start

```bash
npm install
npm run dev
```

Open composition **SolarisPitch** (1280×720, 30fps, 90s).

## Render

```bash
npx remotion render SolarisPitch out/solaris-pitch.mp4
```

## Scenes

| Scene | Time | Intent |

| Title | 0–8s | Brand + one human sentence |
